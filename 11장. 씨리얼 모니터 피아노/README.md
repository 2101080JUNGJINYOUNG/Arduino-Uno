#### 실습과제1
#### 씨리얼 모니터 피아노 실습과제1
#### 시리얼로 입력받은 숫자에 따라 부저로 계이름 재생
부저는 디지털 2번 핀에 연결.
시리얼 모니터에 1~8 사이의 정수를 입력하면 해당 계이름 재생: 1->도(C4), 2->레(D4), 3->미(E4), 4->파(F4), 5->솔(G4), 6->라(A4), 7->시(B4), 8->도(C5).
1~8 범위를 벗어난 값이 입력되면 소리 끔(noTone).
한 번 재생된 음은 다음 입력이 들어올 때까지 계속 울림 (별도의 duration 제어 없음).

#### TIP
tone() / noTone() 함수 이용.
음계별 주파수는 pitches.h에 정의된 상수(NOTE_C4 등) 이용.
