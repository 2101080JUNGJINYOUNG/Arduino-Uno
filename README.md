# Arduino Uno 실습 정리

국립군산대학교 임베디드소프트웨어공학과 수업에서 Arduino Uno 보드로 진행한 실습들을 정리한 저장소입니다.

## 배운 것 / 깨달은 것 / 성취한 것

디지털 입출력부터 시작해서 스위치 디바운싱, FND 제어, 직렬통신, 아날로그 입출력, 인터럽트, 센서(CdS·써미스터) 활용까지 한 챕터씩 밟아오면서, loop() 안에서 시간과 상태를 다루는 감각이 가장 크게 늘었다고 느꼈습니다. 특히 delay()로 시간을 흘려보내는 방식과 millis()/인터럽트로 상태를 관리하는 방식의 차이를 직접 버그를 겪으며 체감한 게 가장 큰 성취였습니다. 소프트웨어 디바운싱 실습에서는 스위치 입력 하나가 얼마나 지저분한 신호인지 알게 됐고, 인터럽트 실습에서는 chkSwOn() 같은 폴링 함수 없이 상태를 바꾸는 게 왜 필요한지 이해하게 됐습니다. CdS 센서·써미스터 실습에서는 아날로그 값을 물리량(전압, 온도)으로 환산하는 과정과, 평균을 내거나 조건을 판단할 때 값을 언제 갱신하고 언제 유지해야 하는지(예: static 변수 사용) 신경 써야 한다는 걸 직접 실수를 통해 배웠습니다.

전체적으로 "센서를 읽는 것"과 "그 값을 올바른 타이밍에, 올바르게 해석해서 반응하는 것"은 완전히 다른 문제라는 걸 실습을 거듭할수록 깨달았습니다.
